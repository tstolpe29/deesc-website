A SINGLE CONVERSATION

Ask once. Keep the context together.

Choose your agents

Select three configured agents. Give them different models or roles, or use the same model with different instructions.

Let them discuss

The agents answer your message and can respond to each other’s reasoning. Choose the number of discussion rounds before sending.

Read the combined answer

A selected agent brings the replies together. Expand the discussion for the original responses, then continue with a follow-up.

Several agents agreeing does not make an answer correct. If a response fails or is unavailable, the run should be read with that gap in mind.

YOUR AGENTS, YOUR CONNECTIONS

Choose the models.
Set the roles.

Configure named agents using registered OpenAI, Claude, local Ollama, or OpenAI-compatible connections. Change the model and instructions without juggling separate chat windows.

Bring your own API keys or local model. Keys are stored encrypted on the connected Windows PC, which must be awake and signed in to run the agents. Provider usage fees still apply.

Where do messages and replies go?

The private host stores your conversation. Selected providers receive your message and relevant conversation context; discussion rounds also receive other agents’ replies. Using a local model does not make the hosted workspace local-only.

These agents produce text. They do not execute commands, browse your files, or control your PC through this chat.
