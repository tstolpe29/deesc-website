How it works

  1. Pick three agents

    Each agent has a model and a role. They can be different models, or the same model with different instructions.

  2. They answer

    The agents reply to your message. With more than one round they also reply to each other. You set the number of rounds before sending.

  3. One agent combines

    A selected agent combines the replies into one answer. The original replies stay available, and you can ask a follow-up.

Limits and privacy

  • Agents agreeing does not make an answer correct. If an agent fails, its reply is missing from the result.
  • Bring your own API keys or local model: OpenAI, Claude, local Ollama, or an OpenAI-compatible connection. Provider usage fees still apply.
  • Keys are stored encrypted on the connected Windows PC, which must be awake and signed in to run the agents.
  • The private host stores the conversation. The selected providers receive your message, the relevant context and, in later rounds, the other agents’ replies. Using a local model does not make the hosted workspace local-only.
  • The agents produce text only. They do not run commands, read your files or control your PC.
